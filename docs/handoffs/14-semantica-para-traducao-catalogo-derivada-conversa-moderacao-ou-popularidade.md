## Gotchas de ambiente (confirmar)

- **`git checkout -- .` antes de implementar:** árvore pode vir com "modificados" que são só **CRLF** — `git diff origin/main --ignore-all-space --stat` vazio ⇒ só EOL; resetar. Memória `phantom-crlf-churn-vs-origin`. Ao stagear, **caminhos explícitos** e **CR=0 E NUL=0** (conferir com `python3`).
- **Bytes de controle literais em regex viram arquivo BINÁRIO pro git.** Usar o escape visível `/[\x00-\x1f]/g`, nunca os bytes crus.
- **`main` em DOIS worktrees** (principal + CI): `git checkout main` falha → **`git checkout -b <nome> origin/main`**. **`gh pr merge --delete-branch` falha o delete local** → mergear com `gh pr merge <N> --squash` e **apagar a branch remota à mão**: `git push origin --delete <branch>`; e mover-se pra `git checkout --detach origin/main` antes de `git branch -D <branch>` local.
- **Squash-merge pode dar 502 transitório** — **pollar `gh pr view <N> --json state` até `MERGED`**.
- **Check do Vercel FALHA no PR** (não-bloqueante — memória `infra-assumptions-vercel-neon`; falha idêntico nos PRs já mergeados). **Gate real** = check **`checks`** do GitHub Actions (`typecheck`+`lint`+`test`) — esperar verde (`gh pr checks <N>`). Main **não** tem branch protection, então Vercel não é gate obrigatório.
- **Issues não fecham com "Fecha #N"** → **`Closes #N`** no corpo do PR ou `gh issue close`.
