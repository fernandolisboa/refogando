## Gotchas de ambiente (confirmar)

- **`git checkout -- .` antes de implementar:** a árvore pode vir com "modificados" que são só **CRLF** — confirmar com `git diff origin/main --ignore-all-space --stat` (vazio ⇒ só EOL) e resetar. Memória `phantom-crlf-churn-vs-origin`. Ao stagear, **caminhos explícitos** e CR=0 (conferir com Python/`grep`; `ugrep` pode engolir args — usar `python3` se em dúvida). (Nesta sessão a árvore veio limpa.)
- **`main` em DOIS worktrees** (principal + CI): `git checkout main` falha → **`git checkout -b <nome> origin/main`** (ou `git checkout --detach origin/main` ao final). **`gh pr merge --delete-branch` falha o delete local** → mergear com `gh pr merge <N> --squash` e **apagar a branch remota à mão**: `git push origin --delete <branch>`.
- **Squash-merge pode dar 502 transitório** — **não re-disparar cegamente**; **pollar `gh pr view <N> --json state` até `MERGED`** (nesta sessão o merge efetivou de primeira, sem 502).
- **Check do Vercel FALHA no PR** mesmo com a infra **ratificada** (memória `infra-assumptions-vercel-neon`, ADR-0010; o cleanup de preview #29 já está em main) — é **não-bloqueante**. O **gate real** é o check **`checks`** do GitHub Actions (~1m37s; `typecheck`+`lint`+`test`) — esperar verde antes do squash-merge (`gh pr checks <N>`).
- **Issues não fecham com "Fecha #N"** (pt-BR não é keyword) → **`Closes #N`** no corpo do PR (funcionou: #6 auto-fechou) ou `gh issue close`.
- **zsh:** `status` é variável **read-only** — não nomear var de loop `status` (usar `st`). **Backtick dentro de `sql\`...\``** (mesmo em comentário SQL) **termina o template literal** → erro de parse; evitar.
- **npm registry** corta pacotes muito novos (memória `npm-registry-publish-cutoff`) — última versão estável **INSTALÁVEL**.
- **Postgres de teste:** ~346 testes em ~130s. `vitest.config.ts` exclui `**/.claude/**`.
- **`ANTHROPIC_API_KEY`** no `.env.local` (gitignored — **nunca commitar/imprimir**); só o `RealClaudeClient` usa; testes nunca chamam a API real.
- **Rascunho de plano** em `docs/plans/` **removido antes do commit**. **`git push` depois de cada commit.** Branch de `origin/main`, **squash-merge**. **Handoffs também via branch + PR** (nunca direto na main).
