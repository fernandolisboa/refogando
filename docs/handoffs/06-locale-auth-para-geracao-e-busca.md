## Processo (inegociável — funcionou nas sessões #3/#4-#5, manter)

Os 8 passos rodam **cada um num subagente fresco** (ferramenta **Agent** para um passo; **Workflow** para fan-out/pipeline). O loop principal **só orquestra e integra** — não faz o trabalho dos passos. Padrão que rendeu bem nesta sessão (replicar):

1. **Explorar** → Workflow com leitores paralelos (issues/PRD/ADRs/código/seam de teste) + síntese num brief auto-suficiente. 2. **Planejar** → Agent escrevendo plano file-by-file (rascunho em `docs/plans/`, **removido antes do commit** — não há convenção de `docs/plans/` no repo). 3. **Revisar o plano** → Workflow multi-lente + **verificação adversarial de cada achado** + veredito com emendas. 4. **Corrigir o plano** → Agent aplica as emendas. 5. **Implementar** → Workflow: **backbone serial** (schema/migração + um **micro-spike** que valida a integração arriscada contra Postgres real ANTES do fan-out) → **fatias paralelas em arquivos disjuntos** → **green-gate único** (typecheck/lint/test/build) que itera até verde. 6. **Code-review** → Workflow: lentes (correção/segurança/qualidade/perf/ADR+CONTEXT/migração) → verificação adversarial → síntese. 7. **Corrigir** → Workflow: fixes em arquivos disjuntos em paralelo + re-green-gate. 8. **Validar e fechar** → **orquestrador**: (opcional) **verify de browser** pra fechar ACs visuais; remover rascunho; branch a partir do `main`; commit; push; PR; **squash-merge**; fechar issues.

**Lições desta sessão:** (a) grelhar SÓ o que congela schema/é irreversível (grelhei `users.locale` nullable, FK ON DELETE, enum de papel, lib de auth) — o resto decidir com default+porquê; (b) um **micro-spike** no início do passo 5 paga: validou de uma vez a factory lazy + testUtils + colunas exigidas pela lib, evitando achados tardios; (c) **verificação adversarial** dos achados (passos 3 e 6) descartou ~10 falsos-positivos e confirmou 3 blockers reais; (d) o **verify de browser** (Playwright MCP) achou um bug de `<html lang>` que os testes não pegavam — vale para qualquer fatia com UI.

## Mapa de propriedade / landmines (para a próxima fatia)

- **Seam do Claude é dormente, não inexistente.** Ativar via `getClaudeClient()` (prod) e `setClaudeClient(new FakeClaudeClient(...))` + `resetDeps()` no `beforeEach` (teste). **Não** chamar a API real em teste. Geração é não-determinística → o `FakeClaudeClient` injeta respostas fixas; testar o **contrato** (schema canônico, taxonomia), não o texto do LLM.
- **Geração conforma ao schema canônico da #3** — não criar "schema de IA" paralelo (CONTEXT: a Receita é a mesma, o que muda é a **Proveniência**). `origin` é **imutável** (trigger na 0001) — geração nasce `ai_chat`/`ai_structured`.
- **Auth/gating já existe (#5).** Persistir/publicar/votar **exigem conta** (ADR-0011): usar `requireSession`/`requireRole`. **Visitante gera efêmero** (não persistido) — geração anônima é permitida, salvar não. Owner do conteúdo gerado = o usuário (`recipe.owner_id`); catálogo segue `owner_id=NULL`.
- **Locale já existe (#4).** Conteúdo gerado nasce num `original_locale`; a leitura localizada é da #3. Não reimplementar i18n.
- **Taxonomia de resultado (#8):** `result_kind` já está no schema (#3). A #8 dá **comportamento** à distinção real-vs-**zoeira** (lúdica, não publicável) vs degradada (receita real). **Receita de zoeira** é personalidade de produto, não erro (CONTEXT).
- **Busca (#6), se escolhida:** FTS por idioma + `unaccent` (extensão já criada na 0000), seccionada por **origem** (catálogo vs gerada). Opera sobre o que existe — **nunca cria** (CONTEXT: Busca/Consulta). Camada semântica (#14) é **outra** fatia; não puxar pgvector aqui.
- **`app_config.default_model`** (entregue na #5) guarda o modelo default (`claude-opus-4-8` qualidade vs `claude-sonnet-4-6` custo) — a #8 **consome** esse valor ao gerar (é o ponto onde a config de Admin vira efeito real).

## Seam de teste (herdada — honrar)

- Integração pela **porta mais alta** (importa o route handler, chama com `Request` cru) contra **Postgres real descartável** (Testcontainers `pgvector/pgvector:pg17` default; `TEST_DATABASE_URL` Neon como fallback; migração pelo endpoint **unpooled**, `max:1`). Invariantes de banco via **cliente postgres.js cru** (`makeSql(inject('databaseUrl'))`, `(err as PostgresError).code` no topo; sob Drizzle o código está em `(err.cause as PostgresError).code`). `truncateAll` descobre tabelas novas sozinho (roda em `beforeEach`).
- **Autenticar testes:** `seedSessionHeaders({ email, role })` de `test/helpers/users.ts` → passa `headers` ao handler; o guard chama `getAuth().api.getSession({ headers })`. Soft-delete: mintar sessão válida e depois `UPDATE users SET deleted_at=now()`.
- **Seam do Claude/Embedder:** `setClaudeClient`/`setEmbedder` de `@/server/deps`; `resetDeps()` no `beforeEach`. Lógica pura (taxonomia, parsing de FTS, resolução de facetas) → unit sem DB.

## Gotchas de ambiente

- **Docker** de pé pro caminho default (Testcontainers). `TEST_DATABASE_URL` (Neon, pooled) presente como fallback — loga "derivando o endpoint direto", informativo. Migrações exigem URL **unpooled**.
- **`.env.local`** (gitignored — **nunca commitar**) tem `DATABASE_URL` (Neon) e **`BETTER_AUTH_SECRET`** (gerado nesta sessão; fail-closed exige ele fora de teste). `.env.example` documenta as vars (incl. `GOOGLE_CLIENT_ID/SECRET` p/ ligar o OAuth dormente, e `BETTER_AUTH_URL` recomendado com OAuth ativo).
- **Versão do Better Auth = `1.6.16`** (não 1.6.18): o registry deste ambiente corta pacotes publicados após ~2026-06-11. API idêntica; bumpável em produção. (Ver memória `npm-registry-publish-cutoff`.)
- **`git push` depois de cada commit.** Branch a partir do `main` (não commitar direto — classifier bloqueia). **Squash-merge** do PR. `gh` autenticado. Escritas no GitHub podem ser barradas pelo classificador; se barrar, o usuário aprova ou roda via `! ...`.
- **Better Auth specifics** (se a fatia tocar auth): `getAuth()` é factory lazy (não chamar no top-level de módulo importado por teste/build); `APIError` expõe o código HTTP em `.statusCode` (number), não `.status` (string); `cookieCache` deve ficar **OFF** (gating lê role/deletedAt vivos).
