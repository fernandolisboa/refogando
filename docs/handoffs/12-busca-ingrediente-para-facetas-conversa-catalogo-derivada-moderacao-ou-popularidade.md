## Gotchas de ambiente (confirmar)

- **`git checkout -- .` antes de implementar:** árvore pode vir com "modificados" que são só **CRLF** — confirmar com `git diff origin/main --ignore-all-space --stat` (vazio ⇒ só EOL) e resetar. Memória `phantom-crlf-churn-vs-origin`. Ao stagear, **caminhos explícitos** e CR=0 **E NUL=0** (conferir com `python3`; `ugrep` pode engolir args).
- **Bytes de controle literais em regex viram arquivo BINÁRIO pro git** (o `route.ts` da #6 virou `Bin` no diff). Usar o **escape visível** `/[\x00-\x1f]/g` (helper `stripControlChars` em `src/domain/search-terms.ts`), nunca os bytes crus.
- **`main` em DOIS worktrees** (principal + CI): `git checkout main` falha → **`git checkout -b <nome> origin/main`** (ou `git checkout --detach origin/main` ao final). **`gh pr merge --delete-branch` falha o delete local** → mergear com `gh pr merge <N> --squash` e **apagar a branch remota à mão**: `git push origin --delete <branch>`.
- **Squash-merge pode dar 502 transitório** — **pollar `gh pr view <N> --json state` até `MERGED`** em vez de re-disparar (nesta sessão efetivou de primeira).
- **Check do Vercel FALHA no PR** (não-bloqueante mesmo com infra ratificada — memória `infra-assumptions-vercel-neon`). **Gate real** = check **`checks`** do GitHub Actions (~1m30s; `typecheck`+`lint`+`test`) — esperar verde antes do squash-merge (`gh pr checks <N>`).

- **zsh:** `status` é var **read-only** — usar `st`. **Backtick dentro de `sql\`...\``** (mesmo em comentário SQL) **termina o template** → erro de parse; evitar.
