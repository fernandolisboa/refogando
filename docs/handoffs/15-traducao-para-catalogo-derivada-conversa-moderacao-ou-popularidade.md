## Gotchas de ambiente (confirmar)

- **`git checkout -- .` antes de implementar:** árvore pode vir com "modificados" que são só **CRLF** — `git diff origin/main --ignore-all-space --stat` vazio ⇒ só EOL; resetar (memória `phantom-crlf-churn-vs-origin`). Ao stagear, **caminhos explícitos** e **CR=0 E NUL=0** (conferir com `python3`; **paths com `[id]`/`[locale]` precisam de aspas** no `git add`).
- **Bytes de controle literais em regex viram arquivo BINÁRIO pro git.** Usar o escape visível `/[\x00-\x1f]/g`, nunca os bytes crus.
- **`main` pode estar em DOIS worktrees** (principal + CI): `git checkout main` pode falhar → **`git checkout -b <nome> origin/main`**. **`gh pr merge --delete-branch` falha o delete local** → mergear com `gh pr merge <N> --squash` e **apagar a branch remota à mão**: `git push origin --delete <branch>`; e mover-se pra `git checkout --detach origin/main` antes de `git branch -D <branch>` local.
- **Squash-merge pode dar 502 transitório** — **pollar `gh pr view <N> --json state` até `MERGED`** (nesta sessão veio MERGED de 1ª).
- **Check do Vercel FALHA no PR** (não-bloqueante — memória `infra-assumptions-vercel-neon`; falha idêntico nos PRs já mergeados; `gh pr checks` retorna **exit 1** por causa dele). **Gate real** = check **`checks`** do GitHub Actions (`typecheck`+`lint`+`test`) — esperar verde (`gh pr checks <N>` e ler a linha `checks`). Main **não** tem branch protection.
- **Issues não fecham com "Fecha #N"** → **`Closes #N`** no corpo do PR (funcionou) ou `gh issue close`.
