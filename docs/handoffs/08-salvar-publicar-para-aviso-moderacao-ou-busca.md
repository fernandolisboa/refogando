## Processo (inegociável — funcionou em #3/#4-#5/#8/#13, manter)

Os 8 passos rodam **cada um num subagente fresco** (**Agent** para um passo; **Workflow** para fan-out/pipeline). O loop principal **só orquestra e integra**. Padrão que rendeu de novo nesta sessão (replicar): 1. **Explorar** → Workflow de leitores paralelos (issue/ADRs/CONTEXT/código/seam) + síntese num brief que **separa o que congela schema (grelhar) do reversível (decidir+porquê)**. 2. **Planejar** → Agent escreve plano file-by-file (rascunho em `docs/plans/`, **removido antes do commit**). 3. **Revisar o plano** → Workflow multi-lente + **verificação adversarial de cada achado** + síntese com emendas. 4. **Corrigir o plano** → Agent. 5. **Implementar** → Workflow: **backbone serial** (deps + schema/migração quando houver + **micro-spike** que valida a integração arriscada contra Postgres real ANTES do fan-out) → **fatias paralelas em arquivos disjuntos** → **green-gate único** que itera até verde. 6. **Code-review** → Workflow: lentes (correção/segurança/qualidade/perf/ADR+CONTEXT) → verificação adversarial → síntese. 7. **Corrigir** → Agent/Workflow + re-green-gate. 8. **Validar e fechar** → orquestrador: validação autoritativa no loop principal; remover rascunho; branch de `origin/main`; commit; push; PR; **squash-merge**; fechar issue.

**Lições desta sessão:** (a) **Grill curto e cirúrgico paga** — 2 perguntas (forma do endpoint + escopo de schema) congelaram o contrato de API cedo; o resto decidido com default+porquê e veto. (b) **O micro-spike provou o fato crítico**: sob Drizzle/postgres.js o `PostgresError` chega em **`err.cause.code`** (`='23514'`); `err.code` top-level é **`undefined`**. `pgCode` lê `err.cause?.code` primeiro. Sem o spike, o catch defense-in-depth (que **nenhum teste de rota exercita** — é código morto via porta alta) poderia estar errado e nunca ser pego. **O spike tem que tocar a integração arriscada de verdade.** (c) **Code-review adversarial** descartou falsos-positivos e confirmou só **nits** (zero blocker/major); 2 nits aceitos (`it.each` twin-routes; teste comportamental do ciclo de pool) **fortaleceram a cobertura de AC** — "entrou/saiu do pool" agora é provado por leitura de terceiro, não só pela coluna.
