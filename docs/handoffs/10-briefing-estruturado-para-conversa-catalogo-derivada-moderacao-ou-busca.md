## Gotchas de ambiente (confirmar)

- **`git checkout -- .` antes de implementar:** a árvore pode vir com arquivos "modificados" que são só **CRLF** — confirmar com `git diff origin/main --ignore-all-space --stat` (vazio ⇒ só EOL) e resetar. Memória `phantom-crlf-churn-vs-origin`. Ao stagear, **caminhos explícitos** e `grep -c $'\r'` = 0. (Nesta sessão a árvore veio limpa.)
- **`main` em DOIS worktrees** (principal + CI): `git checkout main` no principal falha → **`git checkout -b <nome> origin/main`**. E **`gh pr merge --delete-branch` falha o delete local** → mergear com `gh pr merge <N> --squash` e **apagar a branch remota à mão**: `git push origin --delete <branch>`.
- **Squash-merge pode dar 502 transitório** (`Merge already in progress`) — **não re-disparar cegamente**; **pollar `gh pr view <N> --json state` até `MERGED`** (nesta sessão o 1º request 502 efetivou; o retry só reportou o lock).
- **Check do Vercel FALHA no PR** (infra Vercel+Neon **não ratificada** — memória `infra-assumptions-vercel-neon`): **não-bloqueante** (`mergeStateStatus=UNSTABLE`, `mergeable=MERGEABLE`). O **gate real** é o check **`checks`** do GitHub Actions (~1m; `typecheck`+`lint`+`test`) — esperar verde antes do squash-merge (`gh pr checks <N>`).
- **Issues não fecham com "Fecha #N"** (pt-BR não é keyword) → **`Closes #N`** no corpo do PR (funcionou: #11 auto-fechou) ou `gh issue close`.
- **zsh:** `status` é variável **read-only** — não nomear var de loop `status` (use `st`).
- **npm registry** corta pacotes muito novos (memória `npm-registry-publish-cutoff`) — última versão estável **INSTALÁVEL**.
- **Postgres de teste:** ~316 testes em ~100s. `vitest.config.ts` exclui `**/.claude/**`.
- **`ANTHROPIC_API_KEY`** no `.env.local` (gitignored — **nunca commitar/imprimir**); só o `RealClaudeClient` usa; testes nunca chamam a API real.
- **Rascunho de plano** em `docs/plans/` **removido antes do commit**. **`git push` depois de cada commit.** Branch de `origin/main`, **squash-merge**.
