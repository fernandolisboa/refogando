## Processo (inegociável — funcionou em #3/#4-#5/#8/#13/#7, manter)

Os 8 passos rodam **cada um num subagente fresco** (**Agent** para um passo; **Workflow** para fan-out/pipeline). O loop principal **só orquestra e integra** — não faz o trabalho dos passos. Padrão que rendeu de novo nesta sessão (replicar):

2. **Planejar** → **Agent** escreve plano file-by-file (rascunho em `docs/plans/`, **removido antes do commit**).
3. **Revisar o plano** → **Workflow** multi-lente (AC/correção, ADR+CONTEXT, code-fit, test-design, completude) + **verificação adversarial de cada achado (default = refutar)** + síntese com emendas. Nesta sessão: 13/14 refutados, 1 emenda real (fixture de tipo quebraria o `tsc` sobre `test/`).
4. **Corrigir o plano** → **Agent**.
5. **Implementar** → **Workflow**: **backbone serial** (motor puro até verde + **micro-spike REAL contra Postgres** que valida a integração arriscada ANTES do fan-out — aqui: o `LEFT JOIN` devolve `text[]` como array JS e FK-nula→`null`) → **fatias paralelas em arquivos DISJUNTOS** (i18n / loader / view+unit / teste de integração) → **green-gate único** que roda `typecheck`+`lint`+`test` e itera até verde. Nesta sessão: **verde no 1º green, zero fix**.
6. **Code-review** → **Workflow**: lentes (correção/segurança/qualidade/perf/ADR+CONTEXT) → verificação adversarial → síntese. Nesta sessão: **merge-ready**, 1 nit (`$`-substitution).

## Gotchas de ambiente (inalterados; confirmar)

- **`git checkout -- .` antes de implementar:** a árvore pode vir com arquivos "modificados" que são só **CRLF** (line-endings), não conteúdo — confirmar com `git diff origin/main --ignore-all-space --stat` (vazio ⇒ só EOL) e resetar. Memória `phantom-crlf-churn-vs-origin`. Ao stagear, **caminhos explícitos** e `grep -c $'\r'` = 0.
- **`main` em DOIS worktrees** (principal + CI): `git checkout main` no principal falha → **`git checkout -b <nome> origin/main`**. E **`gh pr merge --delete-branch` falha o delete local** → mergear com `gh pr merge <N> --squash` e **apagar a branch remota à mão**: `git push origin --delete <branch>`.
- **Check do Vercel FALHA no PR** (infra Vercel+Neon **não ratificada** — memória `infra-assumptions-vercel-neon`): **não-bloqueante** (`mergeStateStatus=UNSTABLE`, `mergeable=MERGEABLE`). O **gate real** é o check **`checks`** do GitHub Actions (`typecheck`+`lint`+`test`) — esperar ele verde antes do squash-merge (`gh pr checks <N>`).
- **Issues não fecham com "Fecha #N"** (pt-BR não é keyword) → **`Closes #N`** no corpo do PR ou `gh issue close`.
- **npm registry** corta pacotes muito novos (memória `npm-registry-publish-cutoff`) — última versão estável **INSTALÁVEL**.
- **Postgres de teste:** `TEST_DATABASE_URL` (Neon pooled; harness deriva o endpoint direto pra migrar). ~243 testes em ~90s. `vitest.config.ts` exclui `**/.claude/**`.
- **`ANTHROPIC_API_KEY`** no `.env.local` (gitignored — **nunca commitar/imprimir**); só o `RealClaudeClient` usa; testes nunca chamam a API real.
- **Rascunho de plano** em `docs/plans/` **removido antes do commit**. **`git push` depois de cada commit.** Branch de `origin/main`, **squash-merge**.
